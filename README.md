# Departamento de Deportes Lincoln - Carpeta de trabajo

Estructura de trabajo para asumir la jefatura del área deportiva.
Cada carpeta tiene documentos base para editar y completar con la realidad del colegio.

## Orden de trabajo sugerido

1. 01-diagnostico y 08-gestion-kpis: con esto se enfrenta la reunión y los primeros 90 días
2. 02-perfil-deportista: adaptar el material que ya existe
3. El resto se llena con la información real del colegio durante la fase de diagnóstico

## Regla de la carpeta

Nada se diseña en el aire. Todo documento que se complete debe salir de una conversación,
un catastro o un dato real del colegio.
